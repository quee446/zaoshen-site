Git 基础与上传 GitHub

今天不写页面，做一件更重要的事：给代码上保险。 学完你会拥有第一个线上仓库，以后每天的学习记录都能被追溯。

⏱ 约 120 分钟 📄 产出 GitHub 仓库 🎯 难度 ★★☆

一、Git 是什么：给代码存档

最好的类比是游戏存档：每打完一关就存一次档，打输了能读档回来。 Git 就是给代码做这件事的工具。

概念游戏里的对应说明
仓库 repository存档文件夹一个被 Git 管理的文件夹
commit一次存档记录「这一刻代码长什么样」
GitHub云存档服务器存放仓库的网站
push上传存档把本地 commit 传到 GitHub
pull下载存档把 GitHub 上的更新拉回本地
为什么必须学 Git：面试官看你的 GitHub 就能判断你是不是真的在写代码。 一个每天有 commit 的仓库，比简历上写「熟悉前端」有说服力一百倍。

二、第一次配置：git config

装完 Git 先报上名号，这两行只做一次：

# 设置全局用户名（会写进每一次 commit 的作者信息）
git config --global user.name "你的名字"

# 设置全局邮箱（建议和 GitHub 账号邮箱一致）
git config --global user.email "you@example.com"

# 检查是否设置成功
git config --global --list
常见坑：名字和邮箱写错了，之后所有 commit 的作者都是错的。 改法很简单：重新执行上面两行覆盖即可。

三、git init 与分支名 main

git init 在一个文件夹里创建仓库，执行后会多出一个隐藏的 .git 文件夹， 所有存档信息都在里面。不要手动删它，删了仓库历史就没了。 

# 进入你的项目文件夹
cd ~/Desktop/zaoshen

# 创建仓库（只需执行一次）
git init

# 把默认分支改名成 main，和 GitHub 保持一致
git branch -M main

# 查看当前状态，确认在 main 分支上
git status
为什么改名 main：Git 老版本默认分支叫 master，GitHub 现在默认叫 main。 两边不一致时第一次 push 会报错，提前改名最省事。

四、连接远程仓库 remote origin

先在 GitHub 上新建一个空仓库（不要勾选 README），拿到它的地址， 然后用 git remote add 把本地和它连起来。 

# origin 是这个远程地址的别名，以后用 origin 就代表它
git remote add origin https://github.com/你的用户名/zaoshen.git

# 查看已经连上的远程仓库
git remote -v

# 第一次推送：-u 把本地 main 和远程 main 绑定，以后直接 git push
git push -u origin main
报错排查：
  • remote origin already exists → 已经连过了，用 git remote set-url origin 新地址 改地址；
  • Authentication failed → 密码要用 Personal Access Token，不是 GitHub 登录密码；
  • rejected (fetch first) → 远程有本地没有的提交，先 git pull --rebase。

五、每天的标准动作

从今天起，每天学完就执行这三步，形成肌肉记忆：

# 第 1 步：把改动放进暂存区（. 表示当前目录所有改动）
git add .

# 第 2 步：存一次档，-m 后面写这次改了什么
git commit -m "D6: Git 基础 + 上传 GitHub"

# 第 3 步：推到 GitHub
git push
命令作用记忆法
git add .把改动放进暂存区「装进箱子」
git commit -m "..."把箱子封上，贴标签「封箱存档」
git push把箱子寄到云端「发货」
commit 信息怎么写：格式统一成 D天数: 今天做了什么， 比如 D6: Git 基础 + 上传 GitHub。 三个月后回头看，一眼就知道每天干了什么。

八、口述题

面试官问：「说说 git add、git commit、git push 的区别。」请用 40 秒讲清楚。

看参考答案

三个动作对应三个区域。git add 把工作区的改动放进暂存区，相当于「装进箱子」； git commit 把暂存区的内容存成一次提交记录，相当于「封箱存档」，此时还在本地； git push 把本地的提交推到远程仓库，相当于「发货」。 顺序不能乱，add 之后才能 commit，commit 之后才能 push。
