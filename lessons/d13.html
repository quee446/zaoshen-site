一 · position 五种值

默认情况下，所有元素都在「文档流」里排队，一个挨一个往下排。 position 决定的是：这个元素还排不排队，以及它站在哪。

值还占位置吗相对谁移动一句话
static占不移动默认值，写了等于没写
relative占相对自己原来的位置微调位置，坑还留着
absolute不占最近的已定位祖先脱离队伍，飘到指定位置
fixed不占浏览器窗口滚动时不动，钉在屏幕上
sticky占滚动到阈值前正常，之后钉住吸顶导航栏
最容易错的一点

「最近的已定位祖先」不等于「父元素」。它指的是往上找，第一个 position 不是 static 的祖先。一路找到 html 都没有，就相对整个页面定位。

记忆口诀：absolute 认「已定位」的祖先，不认「亲爹」。

1.1 四个方向属性

定位之后，用这四个属性告诉它「站哪」。写 top: 0; right: 0; 就是贴住包含块的右上角。

css
/* 定位元素离上边 0，离右边 0 —— 也就是贴右上角 */
top: 0;      /* 离包含块上边多远 */
right: 0;    /* 离包含块右边多远 */
bottom: 0;   /* 离包含块下边多远 */
left: 0;     /* 离包含块左边多远 */

如果同时写 left 和 right，且元素没设宽度，元素会被拉伸到两边都贴住。 权威参考：MDN · position。

1.2 relative vs absolute 最大区别

对比项relativeabsolute
原来的位置还占着，后面的元素不会挤上来空出来了，后面的元素会补位
相对谁移动相对自己原来的位置相对最近的已定位祖先
典型用途给子元素当「定位参照物」角标、下拉菜单、弹层

记忆口诀：relative 是「人走了，座位还留着」；absolute 是「人走了，座位也没了」。

1.3 fixed vs sticky 最大区别

对比项fixedsticky
参照物浏览器窗口最近的滚动容器
是否占位不占，脱离文档流占，还在队伍里
生效条件直接生效必须写 top / bottom 等阈值
典型用途回到顶部按钮、悬浮客服吸顶导航栏、表格表头

记忆口诀：fixed 是「钉在屏幕上」，sticky 是「滚到边上才粘住」。

二 · z-index 与层叠上下文

元素脱离文档流之后可能互相盖住。z-index 决定谁在上面。

规则说明
数值越大越靠上z-index: 10 盖住 z-index: 1
只对已定位元素生效必须配合 relative / absolute / fixed / sticky
默认是 auto不写时按 HTML 顺序，后面的盖住前面的
可以写负数z-index: -1 会跑到父元素背景下面
面试必问：z-index 为什么不生效？

① 没写 position。元素还是 static，z-index 直接被忽略。最常见。

② 父元素形成了层叠上下文。子元素的 z-index 再大，也大不过父元素那一层。

③ 数值相同。按 HTML 顺序，后面的盖住前面的。

2.1 谁创建了层叠上下文

css
/* 以下任一属性都会创建「层叠上下文」，把子元素关在里面 */
position: relative;      /* 配合 z-index 不是 auto 时 */
opacity: 0.9;            /* 只要小于 1 就会 */
transform: scale(1);     /* 只要不是 none 就会 */
filter: blur(0);         /* 只要不是 none 就会 */
will-change: transform;  /* 提前声明也会 */

记忆口诀：opacity / transform / filter 一出现，子元素的 z-index 就「出不了门」。

第 2 步 · 父元素加定位参照

在 .card 里加一行 position: relative;。这一行是整节课的关键。

css
/* 单张卡片：等分剩余空间 + 最小宽度 200px（换行开关） */
.card {
  background-color: #ffffff;  /* 卡片底色 */
  border: 1px solid #e0e0e0;  /* 卡片边框 */
  border-radius: 8px;         /* 圆角 */
  padding: 20px;              /* 内边距 */
  flex: 1;                    /* 平分剩余空间，让卡片等宽 */
  min-width: 200px;           /* 最小宽度，窄屏时触发换行 */
  position: relative;         /* 关键！让子元素 .badge 相对本卡片定位 */
}

第 3 步 · 写角标样式

css
/* 右上角 NEW 角标：绝对定位到卡片右上角 */
.badge {
  position: absolute;         /* 脱离文档流，相对 .card 定位 */
  top: 0;                     /* 贴住卡片上边 */
  right: 0;                   /* 贴住卡片右边 */
  background-color: #b45309;  /* 角标底色（赭石） */
  color: #ffffff;             /* 角标文字白色 */
  font-size: 12px;            /* 角标字号 */
  font-weight: 700;           /* 加粗，让 NEW 更醒目 */
  padding: 2px 8px;           /* 上下 2px，左右 8px */
  border-radius: 0 8px 0 8px; /* 只圆右上和左下，贴合卡片圆角 */
  letter-spacing: 0.5px;      /* 字间距，让 NEW 更舒展 */
}

第 4 步 · 验收

卡住了？按这个顺序排查

角标跑到页面右上角 → .card 忘了写 position: relative。

角标把标题挤下去了 → .badge 的 position: absolute 没生效，检查拼写。

角标盖住卡片边框 → 正常，top: 0 就是贴边。想往里缩改成 top: 8px; right: 8px。

圆角方向不对 → border-radius 的顺序是「左上 右上 右下 左下」。

五 · 动手：悬浮「回到顶部」按钮

这是 position: fixed 的经典用法：按钮永远钉在屏幕右下角，滚动时不动。

html

↑
css
/* 悬浮回到顶部按钮：固定在屏幕右下角 */
.back-top {
  position: fixed;            /* 相对浏览器窗口定位，滚动时不动 */
  right: 24px;                /* 离窗口右边 24px */
  bottom: 24px;               /* 离窗口下边 24px */
  width: 48px;                /* 按钮宽度 */
  height: 48px;               /* 按钮高度 */
  background-color: #1a1a1a;  /* 按钮底色（墨色） */
  color: #ffffff;             /* 箭头颜色白色 */
  border-radius: 50%;         /* 50% = 正圆 */
  display: flex;              /* 关键：a 默认 inline，宽高会失效 */
  align-items: center;        /* 垂直居中 */
  justify-content: center;    /* 水平居中 */
  font-size: 20px;            /* 箭头字号 */
  text-decoration: none;      /* 去掉链接下划线 */
  z-index: 100;               /* 保证盖在其他内容上面 */
}
fixed 与 absolute 一句话区分

absolute 相对已定位的祖先；fixed 相对浏览器窗口，跟祖先没关系。

所以「回到顶部」用 fixed，「卡片角标」用 absolute。

七 · 口述题

不看代码，用自己的话讲 30 秒

题目：「absolute 相对谁定位？为什么做角标时父元素一定要写 relative？」

讲完了，对照参考答案
absolute 相对最近的已定位祖先定位 —— 往上找，第一个 position 不是 static 的祖先。 如果一路找到 html 都没有，就相对整个页面定位。

做角标时，我们希望角标贴在卡片的右上角，所以必须让卡片成为「已定位祖先」，也就是给 .card 写 position: relative。 不写的话，卡片还是 static，浏览器一路往上找，最后相对页面定位，角标就飞到页面右上角去了。

markdown · 抄进笔记
## D13 · 定位 position
- static（默认，不定位）/ relative（占位，相对自己）/ absolute（不占位，相对已定位祖先）
- fixed（不占位，相对浏览器窗口）/ sticky（滚动到阈值后钉住）
- 方向属性：top / right / bottom / left
- 角标配方：父元素 position: relative + 子元素 position: absolute; top:0; right:0
- 回到顶部配方：position: fixed; right:24px; bottom:24px
- z-index 只对已定位元素生效；数值越大越靠上
- z-index 不生效三大原因：没写 position / 父元素有 opacity、transform、filter / 数值相同
- 坑：absolute 认「已定位」的祖先，不认「亲爹」
