一、无序列表 ul 与有序列表 ol

列表由「容器 + 条目」两层组成：ul 或 ol 是容器， 里面只能直接放 li（列表项）。

标签长什么样什么时候用
ul前面是小圆点 •没有先后顺序：爱好、技能、导航链接
ol前面是 1. 2. 3.有先后顺序：步骤、排行榜
li一条内容必须直接放在 ul 或 ol 里面

    • 二、链接 a 与 href

    a 是链接，href 是它要跳去的地址。 这是 HTML 里最重要的标签之一——整个互联网就是靠链接连起来的。

    写法含义
    href="https://github.com"跳到别的网站，必须写完整协议头
    href="profile.html"跳到同文件夹下的另一个页面（相对路径）
    href="#about"跳到本页 id 为 about 的位置（锚点）
    target="_blank"在新标签页打开

    三、图片 img 的 src 与 alt

    img 是单标签，没有 。 它有两个必写属性：

    • src：图片的路径，写错就显示不出来；
    • alt：图片加载失败时显示的文字，也是读屏软件念给盲人听的内容。
    alt 不是可选项。图片挂了、网速慢、用户用读屏软件， 都只能靠 alt 知道这里是什么。装饰性图片才写 alt=""（空字符串）。

    四、相对路径怎么写

    「图片不显示」是新手第一大坑，九成是路径写错。规则只有三条：

    写法含义例子
    avatar.jpg同一个文件夹里index.html 和 avatar.jpg 并排
    images/avatar.jpg下一级文件夹里images 文件夹里的图
    ../avatar.jpg上一级文件夹里往上一层去找

    排查方法：按 F12 打开开发者工具，切到 Console，看到红色的 404 就是路径错了。

    色盲友好的验收方式：不看颜色，只看两件事—— ① 图片区域有没有出现画面；② Console 里有没有 404 报错。

    七、口述题

    面试官问：「img 的 alt 有什么用？不写会怎样？」请用 30 秒讲清楚。

    看参考答案

    alt 是图片的替代文字，有三个作用：图片加载失败时显示它；读屏软件念给视障用户听； 搜索引擎靠它理解图片内容。不写 alt 会损害无障碍体验，也不符合 HTML 规范。 纯装饰性图片写 alt="" 告诉读屏软件跳过。
