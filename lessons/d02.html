HTML 结构与 head / body

昨天你让浏览器显示了名字，今天要搞明白「为什么能显示」。 这一课只有四件事：head 与 body 的分工、标题的六个层级、段落与换行、标签怎么嵌套。

⏱ 约 110 分钟 📄 产出 index.html 升级版 🎯 难度 ★☆☆

一、head 和 body 的分工

一个 HTML 文档的结构是固定的：html 是根，里面只有两个儿子—— head 和 body。它们是兄弟关系，不是父子。

区域给谁看放什么
head 浏览器、搜索引擎、读屏软件 title、meta charset、meta viewport、引入 CSS 的 link
body 用户 标题、段落、图片、链接、按钮……所有看得见的东西

记忆法：head 是「设置」，body 是「内容」。 写代码时先问自己一句：这行字用户要不要看见？要 → body，不要 → head。

二、标题 h1 ~ h6

HTML 给了六级标题，h1 最大最重要，h6 最小。 它们的作用不是「把字变大」，而是表达层级。

标签语义典型用法
h1页面主标题整页只有一个，比如「我的个人主页」
h2大段落标题「关于我」「我的爱好」「联系方式」
h3小段落标题「关于我」下面的「教育经历」
h4 ~ h6更细的层级一般很少用到，别为了字小就用 h6
铁律：一个页面只写一个 h1。 它是这一页的主题，写两个搜索引擎就不知道你到底在讲什么。 想要字大，用 CSS 的 font-size，不要拿 h4 冒充 h2。

三、段落 p 与换行 br

p 是一个段落。浏览器会自动在段落前后留出空白，所以两段文字之间不用手动加空行。

br 是强制换行，它是单标签，没有
。 只在「同一段里必须断行」时用，比如地址、诗歌。

新手最迷惑的一点：在代码里连续敲十个回车，页面上不会出现十个空行。 HTML 会把连续的空格和换行压缩成一个空格。想控制间距，以后用 CSS 的 margin。

四、标签嵌套规则

标签像盒子套盒子，必须遵守三条：

  • 先开的后关：

    字

     对，交叉就错；
  • 块级不能塞进段落：p 里不能放 div、h2 这种块级元素；
  • 缩进只是给人看的：浏览器不在乎你缩几个空格，但队友在乎。

七、口述题

面试官问：「为什么一个页面只能有一个 h1？」请用 30 秒讲清楚。

看参考答案

h1 表达的是这一页的主题，就像一篇文章只有一个标题。 写多个 h1，搜索引擎无法判断哪个是重点，读屏软件的大纲也会乱。 需要更细的层级就用 h2、h3 往下排，需要字大就用 CSS 的 font-size。
