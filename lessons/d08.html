CSS 引入与选择器

从今天开始，页面不再只有黑白骨架。CSS 的第一课只解决两件事： 样式怎么接进来，以及怎么「选中」你想改的那个元素。

⏱ 约 120 分钟 📄 产出 style.css 🎯 难度 ★★☆

一、三种引入方式

CSS 要生效，必须先和 HTML 建立联系。有三种方式，优先级从高到低推荐程度正好相反： 外部引入最推荐，内联最不推荐。

方式写法写在哪评价
外部引入 head 里 ✅ 最推荐，多页面共用一份
内部引入 head 里 ⚠️ 只适合单页小 demo
内联样式

标签属性上 ❌ 最难维护，只临时调试用
为什么外部引入最好？ 改一处，所有页面一起变；浏览器还能缓存这个文件，第二次打开更快。 这也是真实项目里唯一会用的方式。

二、三种选择器：标签 / class / id

选择器就是「你要改谁」。最常用的三种，记住一个口诀就够了： class 像校服，id 像学号。

选择器写法选中谁能重复吗
标签选择器p页面上所有

—
class 选择器.card所有 class="card" 的元素✅ 可以重复，像校服
id 选择器#header唯一那个 id="header"❌ 一页只能一个，像学号
 
/* 标签选择器：所有段落都变灰 */
p {
  color: #666;
}

/* class 选择器：点号开头，可以给很多元素穿同一件「校服」 */
.card {
  padding: 24px;
}

/* id 选择器：井号开头，一页只能有一个 */
#header {
  height: 64px;
}
命名规则： 只能用字母、数字、-、_，不能以数字开头，不能有空格。 class="my card" 是两个 class，不是名字里带空格。

三、优先级与权重

当两条规则都想改同一个元素时，谁赢？看权重。权重高的赢，权重一样时后写的赢。

选择器权重记忆
#id100学号，最硬
.class10校服，中等
标签1最弱
 
/* 权重 1 */
p { color: blue; }

/* 权重 10 —— 赢过上面那条 */
.text { color: green; }

/* 权重 100 —— 赢过上面两条 */
#intro { color: red; }
实战建议：别用 id 写样式。 id 权重 100 太高，后面想覆盖只能再写一个 id 或者加 !important， 越写越乱。id 留给 JS 找元素和页面锚点用。

四、后代选择器

中间用空格隔开，意思是「里面的」。它比直接写标签更精准，不会误伤页面上其他的同类标签。 

/* 只改 class 是 card 的元素「里面」的 h2 */
.card h2 {
  font-size: 20px;
}

/* 对比：这样会改掉页面上所有 h2，包括导航栏里的 */
h2 {
  font-size: 20px;
}
读法：从右往左读。.card h2 读作「h2，它在 .card 里面」。 面试时这样读，思路最清楚。

七、口述题

用 60 秒解释：「class 和 id 有什么区别？什么时候用哪个？」

看参考答案

class 可以重复使用，一个页面上很多元素可以共用同一个 class，像校服； id 在一页里必须唯一，像学号。 写样式时优先用 class，因为 class 权重 10，好覆盖、好复用； id 权重 100 太高，一般只留给 JS 找元素和页面锚点跳转用。
