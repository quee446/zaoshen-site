二、复盘怎么写才有用

复盘不是抄笔记。抄一遍笔记只是「手在动」，脑子没动。 真正有用的复盘只回答三个问题：

问题要写成什么样
这周我真正会了什么？ 写「能独立写出一个带导航的个人主页」，不写「学了 HTML」
哪里还卡着？ 写「label 的 for 和 id 绑定还不熟」，不写「有点难」
下周怎么补？ 写「明天重写一遍报名表，不看参考代码」，不写「多练习」 
## 第 1 周复盘（2026-10-19）

### 我真正会了什么
- 能独立写出一个带 header / nav / main / footer 的个人主页
- 能用 git add / commit / push 把代码推上 GitHub

### 哪里还卡着
- label 的 for 和 input 的 id 绑定，写的时候还要想一下
- 相对路径 ../ 和 文件夹/ 的区别，偶尔写反

### 下周怎么补
- 明天重写一遍报名表，不看参考代码
- 每天新内容开始前，先做 3 道上周的自测题

三、间隔重复排期

遗忘是正常的，对抗遗忘最省力的办法是在快忘的时候复习一次。 推荐节奏：

时间点做什么花多久
当天学完做本课自测题10 分钟
第 2 天口头回答 3 个核心问题5 分钟
第 4 天不看笔记重写一遍关键代码15 分钟
第 7 天做一遍全部自测题10 分钟
第 15 天给「三个月前的自己」讲一遍10 分钟
为什么有效：每次「回忆」都会让记忆痕迹变深一次。 重看笔记是「输入」，做自测是「提取」——提取比重看有效得多，这叫检索练习。
