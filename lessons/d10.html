文本、背景、边框

今天把「能看」变成「好看」。四个属性就能让一个白底黑字的页面 变成浮在渐变背景上的白色卡片。

⏱ 约 110 分钟 📄 改造个人简介页 🎯 难度 ★★☆

一、text-align 文字水平对齐

text-align 管的是盒子里面文字怎么排，不是盒子本身的位置。 这是新手最容易搞混的一点。

值效果
left靠左（默认）
center居中
right靠右
关键区别： text-align: center 让文字居中，盒子还是占满整行； margin: 0 auto 让盒子居中。想居中一个卡片，用后者。

二、line-height 行高

行高控制每行文字占的高度。推荐写不带单位的倍数，比如 1.6， 它会跟着字号自动缩放，比写死 24px 更好维护。 

body {
  font-size: 16px;
  line-height: 1.6;  /* 16 × 1.6 = 25.6px，跟着字号自动变 */
}
行高观感
1.0 ~ 1.2太挤，像说明书
1.5 ~ 1.8✅ 正文最舒服的区间
2.0 以上太散，段落失去整体感

三、background 与渐变

background 可以写纯色，也可以写渐变。渐变比纯色更有层次感， 苹果官网大量使用。 

/* 纯色 */
body {
  background: #f5f5f7;
}

/* 线性渐变：135deg 是方向，后面两个是起止颜色 */
body {
  background: linear-gradient(135deg, #667eea, #764ba2);
}
135deg 怎么理解： 0deg 是从下往上，90deg 是从左往右，135deg 就是从左上往右下斜着走。 想换个方向，改这个角度就行。

四、border-radius 与 box-shadow

这两个属性负责「柔和感」。圆角去掉尖锐的角，阴影制造浮起来的错觉。 

.card {
  border-radius: 12px;                        /* 半径 12px 的圆角 */
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12); /* 水平 垂直 模糊 颜色 */
}

.avatar {
  border-radius: 50%;  /* 50% = 正方形变圆形 */
}
box-shadow 第几个值含义
第 1 个水平偏移（正数往右）
第 2 个垂直偏移（正数往下）
第 3 个模糊半径（越大越柔）
第 4 个颜色（用 rgba 带透明度）
阴影颜色一定要带透明度。 写 rgba(0,0,0,.12) 而不是 #000， 否则阴影会像一块黑胶布，非常脏。

七、口述题

用 60 秒解释：「text-align: center 和 margin: 0 auto 有什么区别？」

看参考答案

text-align: center 是给盒子写的，它让盒子里面的文字居中， 盒子本身还是占满整行。 margin: 0 auto 是让盒子本身水平居中， 原理是左右 margin 设为 auto，把剩余空间平分。 所以居中一个卡片用 margin: auto，居中一段文字用 text-align: center。
