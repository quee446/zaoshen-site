过渡与动画

苹果官网那种「轻轻浮起」的手感，其实只有两行 CSS。 今天把 transition 和 transform 彻底搞懂。

⏱ 约 120 分钟 📄 产出悬浮卡片 🎯 难度 ★★★

一、transition 四要素

transition 让属性的变化「慢慢发生」，而不是瞬间跳变。它由四部分组成：

要素属性名例子
过渡哪个属性transition-propertytransform
持续多久transition-duration0.2s
速度曲线transition-timing-functionease
延迟多久开始transition-delay0s
 
/* 完整写法 */
.card {
  transition-property: transform;
  transition-duration: 0.2s;
  transition-timing-function: ease;
  transition-delay: 0s;
}

/* 简写：最常用，四个值按顺序写，后两个可省 */
.card {
  transition: transform 0.2s ease;
}
时长建议 0.15s ~ 0.3s。 太短看不出动画，太长会显得迟钝。苹果官网的悬浮效果基本都在 0.2s 左右。

二、transition 写在默认状态还是 hover 里

这是最容易写错的地方，直接决定手感。

写在哪移入移出
.card（默认状态）✅ 有动画✅ 有动画
.card:hover✅ 有动画❌ 瞬间弹回
 
/* ✅ 正确：写在默认状态，进出都平滑 */
.card {
  transition: transform 0.2s ease;
}
.card:hover {
  transform: translateY(-4px);
}

/* ❌ 错误：写在 hover 里，移出会瞬间弹回 */
.card:hover {
  transition: transform 0.2s ease;
  transform: translateY(-4px);
}
原理： transition 是「从当前状态过渡到新状态」的规则。鼠标移出时，元素回到默认状态， 它读的是默认状态里的 transition。写在 hover 里，移出时就没有规则可读了。

三、transform 三种常用变换

函数作用例子
translate位移translateY(-4px) 往上挪 4px
scale缩放scale(1.02) 放大 2%
rotate旋转rotate(45deg) 转 45 度
 
/* 多个变换写在一起，用空格隔开，顺序会影响结果 */
.card:hover {
  transform: translateY(-4px) scale(1.02);
}
为什么用 transform 而不是改 top / left？ transform 不触发重排（reflow），只走合成层，性能好得多。 动画里优先用 transform 和 opacity，这是性能铁律。

四、卡片悬浮手感配方

把前面学的拼起来，就是苹果官网那种手感： 

.card {
  background: #fff;
  border-radius: 12px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
  /* ① 过渡写在默认状态，进出都平滑 */
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card:hover {
  /* ② 往上浮 4px */
  transform: translateY(-4px);
  /* ③ 阴影加深，浮得更高 */
  box-shadow: 0 12px 32px rgba(0, 0, 0, 0.16);
}
配方三件套： 位移往上 + 阴影加深 + 过渡 0.2s。 位移和阴影要同时过渡，所以 transition 里用逗号写两个属性。

五、transform 会创建层叠上下文

这是 D13 那个 z-index 坑的延伸，面试常考。 

/* 父元素只要写了 transform（哪怕 translate 0），
   就会创建层叠上下文，子元素的 position: fixed 会失效 */
.parent {
  transform: translateZ(0); /* 常见于性能优化写法 */
}

.child {
  position: fixed; /* ❌ 不再相对窗口，而是相对 .parent */
  top: 0;
}
结论： 给祖先元素加 transform 要小心。如果里面有 fixed 定位的元素（比如弹窗、回到顶部按钮）， 它会突然「跑偏」。排查时先看祖先有没有 transform。

六、尊重用户的减少动效设置

有些用户对动效敏感，看动画会头晕。系统里有「减少动态效果」开关， CSS 可以用媒体查询读到它。 

@media (prefers-reduced-motion: reduce) {
  * {
    /* 把动画时长压到几乎为 0，等于关掉动效 */
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
  }
}
这是无障碍的基本礼貌。 面试时能主动提到 prefers-reduced-motion，是很加分的细节。

九、口述题

用 60 秒解释：「怎么做出卡片悬浮时轻轻浮起的效果？」

看参考答案

分三步。第一，在卡片的默认状态写 transition: transform 0.2s ease, box-shadow 0.2s ease， 让位移和阴影都平滑过渡。 第二，在 :hover 里写 transform: translateY(-4px)，让卡片往上浮 4px。 第三，同时把 box-shadow 加深，制造浮得更高的错觉。 关键是 transition 一定要写在默认状态，否则鼠标移出时会瞬间弹回。
