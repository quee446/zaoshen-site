显示模式与 Flex 入门

为什么 div 总是独占一行，span 却能并排？答案在 display。 今天用 Flex 做出人生第一个横向导航栏。

⏱ 约 120 分钟 📄 产出 nav.html 🎯 难度 ★★★

一、display 的四种值

display 决定一个元素「怎么占位置」。四种值覆盖了 90% 的场景。

值独占一行能设宽高典型标签
block✅ 是✅ 能div、p、h1
inline❌ 否❌ 不能span、a
inline-block❌ 否✅ 能按钮、标签
none——直接不显示，也不占位置
inline 元素设 width / height 是无效的。 这是新手最常踩的坑：给 写 width: 100px 没反应， 因为 a 默认是 inline。改成 inline-block 或 block 才生效。
display: none 和 visibility: hidden 的区别： none 是彻底消失、位置也不留；hidden 是看不见但位置还占着。

二、flex 容器 = 写了 display: flex 的盒子

给父元素写 display: flex，它就成了 flex 容器， 它的直接子元素会自动横排。 

          
  Z  
  
    ...
   

.nav {
  display: flex;  /* 这一行让子元素横排 */
}
只影响直接子元素。 孙子辈（子元素的子元素）不受影响。想让孙子也横排，得给那一层也写 display: flex。

三、Flex 三开关

记住三个属性，就能做出绝大多数横向布局：

属性管什么常用值
display: flex开关：让子元素横排flex
justify-content主轴（默认左右）怎么排space-between、center
align-items交叉轴（默认上下）怎么对齐center
 
.nav {
  display: flex;              /* ① 横排 */
  justify-content: space-between; /* ② 两端对齐，中间等分 */
  align-items: center;        /* ③ 垂直居中 */
  height: 64px;
  padding: 0 24px;
}
导航栏三件套： display: flex + justify-content: space-between + align-items: center。 这三行能解决 80% 的导航栏需求，背下来。

四、text-align 和 align-items 的区别

这是最容易混的一对。一句话记法：text 开头的一定是管文字的。

属性管谁写在哪
text-align盒子里面文字的水平对齐任意元素
align-itemsflex 容器里子元素的交叉轴对齐flex 容器（父）
常见错误： 想让导航栏里的 logo 和链接垂直居中，写了 text-align: center —— 没用。 要写 align-items: center，因为你要对齐的是子元素，不是文字。

七、口述题

用 60 秒解释：「text-align 和 align-items 有什么区别？各自用在哪？」

看参考答案

text-align 管的是盒子里面文字的水平对齐，写在任意元素上都行， 比如让一段文字居中。 align-items 是 flex 的属性，管的是 flex 容器里子元素在交叉轴上的对齐， 写在父元素上，比如让导航栏的 logo 和链接垂直居中。 记法很简单：text 开头的一定是管文字的。
