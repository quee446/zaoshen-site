第 1 周 · 环境 + HTML 入门 / D1

环境搭建与第一个网页

今天不写复杂代码，只做一件事：让浏览器里出现你自己的名字。 做完你会明白——网页不过是一个纯文本文件，浏览器负责把它翻译成画面。

⏱ 约 120 分钟 📄 产出 index.html 🎯 难度 ★☆☆

一、网页到底是什么

先破一个迷思：网页不是「软件」，也不是什么神秘的东西。 它就是一个纯文本文件，后缀叫 .html。 你用记事本打开它，看到的是文字；用浏览器打开它，看到的是画面。

浏览器做的事情只有一件：读这个文件，把里面的标签翻译成看得见的东西。 所以写网页的本质，是给内容贴标签——告诉浏览器「这段是标题」「那段是段落」。

一句话记住：HTML 不是编程语言，是「贴标签的语言」。 它不会算数、不会判断，只负责说明「这块内容是什么」。

二、装工具：VS Code 与 Git

今天只需要两个工具，都是免费的：

工具干什么用怎么装
VS Code 写代码的编辑器，有颜色高亮、自动补全 官网 code.visualstudio.com 下载，拖进「应用程序」
Git 给代码存档，以后能上传到 GitHub 终端执行 brew install git

装完在终端验证一下，能出版本号就算成功：

# 查看 Git 版本，能打印出版本号就说明装好了
git --version

# 创建今天的工作文件夹（-p 表示父目录不存在就一起创建）
mkdir -p ~/Desktop/zaoshen/day1
常见坑：命令敲完没反应，多半是路径写错了。 终端里 ~ 代表你的用户主目录，别把它当成普通字符。

三、写出第一个 index.html

在 VS Code 里打开 day1 文件夹，新建文件 index.html， 把下面九行原样敲进去（不要复制粘贴，手敲一遍肌肉记忆才长出来）： 

                          
                      
                                   
                   
  我的第一个网页          
                                  
                                   
  
你好，我是 XXX

保存（⌘ + S），然后在 Finder 里双击 index.html， 浏览器就会打开它，页面上出现你的名字。

验收标准（色盲友好）：不看颜色，只看两件事—— ① 浏览器标签页上的文字是不是「我的第一个网页」； ② 页面正文里有没有出现你的名字。

八、口述题

面试官问：「说说 head 和 body 的区别。」请用 30 秒讲清楚。

看参考答案

head 是给浏览器和搜索引擎看的设置区，用户看不见，里面放 title、meta charset、引入 CSS 的 link。 body 是用户能看见的内容区，页面上所有文字、图片、按钮都在这里。 两者是兄弟关系，都直接包在 html 里。
