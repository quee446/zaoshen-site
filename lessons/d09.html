盒模型

页面上每一个元素都是一个「盒子」。搞懂盒子的四层结构， 你才知道为什么明明写了 300px 却撑破了布局。

⏱ 约 120 分钟 📄 产出卡片组件 🎯 难度 ★★☆

一、盒模型四层

从里到外一共四层。用寄快递来记最牢：

层CSS 属性快递类比
内容content（width / height）你要寄的物品
内边距padding物品周围的泡沫
边框border纸箱的箱壁
外边距margin箱子与箱子之间的空隙
口诀：内容 → 内边距 → 边框 → 外边距。 从里往外数，顺序永远不变。 
.box {
  width: 300px;          /* 内容宽度 */
  padding: 24px;         /* 内边距：内容到边框的距离 */
  border: 2px solid #ddd;/* 边框：2px 实线 */
  margin: 40px;          /* 外边距：盒子外面的空隙 */
}
padding 和 margin 最容易混： padding 在边框里面，会把盒子撑大，背景色也会铺过去； margin 在边框外面，是透明的，不显示背景色。

二、box-sizing: border-box 为什么必须写

默认是 content-box：你写 width: 300px，只是内容 300px。 再加上左右 padding 和 border，实际占的宽度就变成 300 + 24×2 + 2×2 = 352px。 三个这样的盒子并排，布局就撑破了。

box-sizingwidth: 300px 表示实际总宽
content-box（默认）只有内容 300px300 + padding + border
border-box连 padding 和 border 一起 300px就是 300px
 
/* 星号选中所有元素，一次性给全站加上，这是行业标配 */
* {
  box-sizing: border-box;
}
一句话记住： 写了 border-box，width 就是你眼睛看到的宽度，padding 和 border 往里挤，不会往外撑。

三、margin: 40px auto 的居中原理

margin: 40px auto 是「上下 40px，左右 auto」的简写。 auto 的意思是：把剩下的空间平均分给左右两边，盒子自然就居中了。 

.card {
  width: 600px;      /* 必须有明确宽度 */
  margin: 40px auto; /* 上下 40px，左右自动平分 → 水平居中 */
}
前提条件：盒子必须有明确宽度。 如果没写 width，块级元素默认占满一整行，没有「剩余空间」可分，auto 就变成了 0，看起来完全没居中。
和 text-align 的区别： margin: auto 让盒子本身居中； text-align: center 让盒子里的文字居中。这是 D10 会细讲的一对。

四、卡片组件配方

一个看起来「浮起来」的卡片，就是五样东西凑齐： 

.card {
  width: 320px;              /* ① 明确宽度 */
  padding: 24px;             /* ② 内边距，内容不贴边 */
  background: #ffffff;       /* ③ 背景色 */
  border-radius: 12px;       /* ④ 圆角 */
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12); /* ⑤ 阴影 */
}
阴影四个值： 水平偏移 0、垂直偏移 8px、模糊半径 24px、颜色。 垂直偏移为正 = 阴影往下，看起来就像卡片浮在纸面上。

七、口述题

用 60 秒解释：「为什么每个项目开头都要写 * { box-sizing: border-box; }？」

看参考答案

因为浏览器默认是 content-box，width 只算内容，padding 和 border 会额外加上去， 写 300px 实际可能变成 352px，几个盒子并排就会撑破布局。 改成 border-box 之后，width 就是最终宽度，padding 和 border 往里挤， 算尺寸的时候不用再心算加法，布局稳定得多。
