第 2 周 · CSS 基础 / D12

Flexbox 布局

昨天学会了横排，今天学会「等分 + 换行」。 一排等宽卡片，窗口缩窄时自动从 3 张变 2 张再变 1 张。

⏱ 约 120 分钟 📄 产出 card.html 🎯 难度 ★★★

一、主轴与交叉轴

Flex 有两个轴。justify 永远跟着主轴走，align 永远跟着交叉轴走。 这句话是整节课的钥匙。

flex-direction主轴交叉轴justify-content 管align-items 管
row（默认）水平垂直左右上下
column垂直水平上下左右
写了 flex-direction: column 之后，两个属性的作用方向会翻转。 这是面试高频陷阱：很多人以为 justify-content 永远管左右，其实它管的是主轴。

二、flex: 1 三件套

flex: 1 是一个简写，展开是三个属性：

属性值意思
flex-grow1剩余空间我全要
flex-shrink1空间不够就一起缩
flex-basis0%起始宽度从 0 开始算
 
.cards {
  display: flex;
  gap: 16px;
}

.card {
  flex: 1;        /* 三张卡片自动等分 */
  min-width: 200px; /* 配合换行用，见下一节 */
}
一句话记住： flex: 1 = 「剩余空间我全要，不够就一起缩」。 三张卡片都写 flex: 1，就自动等宽。

三、flex-wrap 与响应式换行

默认是 nowrap，放不下就硬挤，子元素会被压扁。 写 flex-wrap: wrap 之后，放不下就换到下一行。 

.cards {
  display: flex;
  flex-wrap: wrap;   /* 换行开关 */
  gap: 16px;
}

.card {
  flex: 1;           /* 等分剩余空间 */
  min-width: 200px;  /* 最小宽度，低于这个就换行 */
}
窗口宽度效果
宽屏（> 700px）3 张并排
中屏（400 ~ 700px）2 张一行
窄屏（< 400px）1 张一行
响应式换行三件套，两个主人： 容器写 flex-wrap: wrap 和 gap； 子元素写 flex: 1 和 min-width。 一个都不能少。

四、gap 与 margin 的区别

做间距，gap 比 margin 干净得多。

方式写在哪最后一行有尾巴吗
gap: 16px容器❌ 没有，只加在元素之间
margin-right: 16px每个子元素✅ 有，最后一个右边也空着
 
/* 用 gap：一行搞定，没有尾巴 */
.cards { display: flex; gap: 16px; }

/* 用 margin：还得单独去掉最后一个 */
.card { margin-right: 16px; }
.card:last-child { margin-right: 0; }

五、justify-content 常用值

值效果典型场景
flex-start靠左（默认）普通列表
flex-end靠右按钮组
center整体居中居中内容
space-between两端顶住，中间等分✅ 导航栏最常用
space-around每个元素两边都有空隙均匀分布的图标
space-between 和 space-around 的区别： between 是「两端贴边，中间分」；around 是「每个元素左右都有空隙」。 导航栏要两端贴边，所以用 between。

八、口述题

用 60 秒解释：「flex: 1 是什么意思？三张卡片等宽是怎么实现的？」

看参考答案

flex: 1 是 flex-grow: 1、flex-shrink: 1、flex-basis: 0% 的简写。 意思是起始宽度从 0 算，剩余空间我全要，空间不够就一起缩。 三张卡片都写 flex: 1，它们就平分容器的剩余空间，所以自动等宽。 再配合 min-width 和 flex-wrap: wrap，窗口变窄时还能自动换行。
